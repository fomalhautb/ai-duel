# 《出牌吧，AI》新手教学对战规格 V1.0

## 1. 教程目标
新手教程不是规则说明页，而是一局经过脚本控制的完整教学对战。玩家需要通过实际操作自然学会：开局前组建 20 张牌的牌组；进入对局前选择英雄；开局抽 5 张牌；每轮根据题目关键词决定派哪个 Agent 上场；Agent 牌和技能牌需要消耗 Token；Agent 上场后会持续留场，后续每轮继续答题且不重复消耗 Token；技能牌可以干扰或改变本轮对局；双方完成出牌后才揭晓完整题目；场上所有 Agent 同时回答题目；只要己方至少一个 Agent 答对，就视为己方本轮答对；如果只有一方答对，该方获得 1 分；如果双方都答对或都答错，则比较双方本轮新打出卡牌消耗的 Token，消耗较少的一方获得 1 分；如果双方本轮 Token 消耗也相同，则双方各获得 1 分；每轮结束后 Token 恢复至新的上限，同时 Token 上限 +1；从第二轮开始，每轮开始抽 2 张牌；先达到 3 分的一方获胜，如果双方同时达到 3 分，则继续进行下一轮，直到出现单独领先的一方。

教程不要一次性展示全部规则，而应在玩家第一次需要使用该规则时再进行提示。

## 2. 通用引导原则
### 2.1 一次只教一个核心概念
禁止连续出现大段规则说明。每一步最多解释一个新概念，并立即要求玩家进行相应操作。例如第一轮只教“派 Agent”；第二轮开始时再教“Agent 会继续留场”和“Token 恢复”；需要使用技能时再介绍技能牌。

### 2.2 使用“聚焦 + 操作”而不是纯文字
需要玩家操作某个元素时，弱化无关区域，高亮目标元素，必要时增加轻微呼吸动画或箭头，显示一句简短提示，并暂时关闭与当前教学无关的操作。引导描述必须使用元素名称，不依赖固定坐标。例如写“高亮手牌中的目标 Agent 卡牌”，不要写“高亮屏幕左下角第二张牌”。

### 2.3 前期强制，后期逐渐放开
教程采用三阶段：第一阶段完全指导，玩家只能完成指定操作；第二阶段半指导，告诉玩家目标，但允许在有限范围内自己选择；第三阶段自由完成，只提示目标，不再告诉玩家具体应该出哪张牌。

### 2.4 教程结果必须可预测
教学局所有 Agent 回答结果使用预设结果。教程脚本必须预先知道每个 Agent 对每道题是否答对、使用技能后结果是否变化、对手每轮会出什么牌、每轮双方 Token 消耗以及最终积分，不能让教学流程依赖随机回答。

## 3. 教程整体结构
完整教程按以下顺序进行：`简化组牌 → 选择英雄 → 开局抽牌 → 第1轮基础出牌 → 第1轮答题与得分 → 第2轮持续留场 + Token成长 + 技能牌 → 第2轮结算 → 第3轮半自由对战 → 胜负结算`。

正常情况下设计成 3 轮结束教学局。如果脚本出现双方同时达到 3 分，则按照正式规则继续增加教学轮次，但教程数据应尽量避免这种情况。

## 4. 阶段一：简化组牌教学
### Step 01｜进入组牌界面
**教学目标：**让玩家知道正式比赛开始前，需要从牌池中选择 20 张牌组成自己的牌组。

进入组牌页面后，系统预先向牌组中加入 17 张卡牌，牌组计数显示 `17 / 20`，剩余牌池中保留若干可选牌。先高亮牌组数量区域，提示：“比赛开始前，先组建你的 20 张牌组。”随后高亮一张指定 Agent 牌，提示：“先加入一张 Agent。”

玩家点击指定 Agent 牌后，卡牌进入牌组，计数从 `17 / 20` 变为 `18 / 20`。

### Step 02｜加入第二张 Agent
高亮另一张 Agent，提示：“不同 Agent 擅长的任务可能不同。”玩家加入后，计数从 `18 / 20` 变为 `19 / 20`。

### Step 03｜加入技能牌
高亮一张教学技能牌，提示：“技能牌不能答题，但可以影响对局。”玩家加入后，计数从 `19 / 20` 变为 `20 / 20`，牌组完成按钮进入可用状态，提示：“牌组完成，开始比赛。”

本阶段不要教学复杂牌组比例、最优构筑方法、卡组流派、卡牌强度、英雄组合或高级技能联动。玩家只需要理解：“比赛前我要选 20 张牌。”

## 5. 阶段二：英雄选择
### Step 04｜选择英雄
进入英雄选择页面。教学局双方使用相同英雄，不专门介绍英雄技能。高亮教学英雄，提示：“选择本局使用的英雄。”玩家点击英雄后出现确认状态，提示：“准备好了，进入对局。”玩家点击开始。

## 6. 阶段三：开局抽牌
### Step 05｜抽取初始手牌
进入战斗页面后，系统播放抽牌动画，从玩家自己的 20 张牌组抽取 5 张牌。必须保证教学需要使用的 Agent 和技能牌出现在初始手牌中。第一次展示手牌时，短暂高亮手牌区域，提示：“这是你的手牌。开局会抽 5 张牌。”提示消失后进入第一轮。

## 7. 第 1 轮：学习最基本的 Agent 出牌
第 1 轮只教学最核心循环：`关键词 → 选择 Agent → Token → 结束出牌 → 揭题 → Agent 回答 → 得分`，不要加入技能牌教学。

### Step 06｜展示题目关键词
轮次开始，显示 `第 1 轮`，系统展示当前题目的关键词或题型信息，完整题目暂不显示。聚焦关键词区域，提示：“正式题目还没揭晓。先根据关键词判断该派谁上场。”随后高亮一张教学指定 Agent，提示：“这次先派它。”

### Step 07｜打出第一个 Agent
高亮目标 Agent 卡牌，同时高亮 Token 区域和该牌 Token Cost，提示：“打出 Agent 会消耗 Token。”此时只能打出指定 Agent，其他卡牌暂时不可操作。玩家打出后，Agent 进入己方场地区域，并播放 Token 扣除动画，例如 `5 → 3`。

首次完成后提示：“Agent 上场后会留在场上，直到它答错题目。”这句话只出现一次。

### Step 08｜结束出牌
高亮“结束出牌”按钮，提示：“准备好了，结束出牌。”玩家点击后，对手执行预设出牌。教学第一轮不要让对手使用复杂技能。

### Step 09｜揭晓题目
双方结束出牌后，播放题目揭晓动画，完整题目出现。提示：“双方都结束出牌后，完整题目才会揭晓。”提示自动消失。

### Step 10｜Agent 回答
场上双方 Agent 开始回答，界面依次表现为 `思考 → 提交答案 → 展示结果`。答案使用系统预设数据。教学第一轮中，玩家 Agent 必须答对，对手结果按照预设脚本决定。

### Step 11｜第一次积分结算
如果玩家答对、对方答错，高亮双方结果，显示 `你的 Agent：正确`、`对方 Agent：错误`，随后玩家 `+1 分`。提示：“只有你答对，这一分属于你。”积分区域播放 `0 → 1` 动画。

## 8. 第 2 轮：学习持续 Agent、抽牌和 Token 成长
### Step 12｜强调存活 Agent
进入第 2 轮后，上一轮答对的玩家 Agent 仍然留在场上。短暂聚焦它，提示：“上一轮答对的 Agent 还在场上。”随后提示：“它会自动参加这一轮，不需要重新付 Token。”这是非常重要的教学节点。

### Step 13｜Token 恢复与成长
高亮 Token，执行恢复与上限增长动画。例如第 1 轮上限为 `5`，第 2 轮显示为 `6 / 6`。提示：“每轮结束后 Token 会恢复，并且下一轮上限 +1。”只解释一次。

### Step 14｜每轮抽 2 张牌
执行抽牌动画，从牌组抽 2 张牌进入手牌。提示：“从第 2 轮开始，每轮抽 2 张牌。”之后不再重复提示。

## 9. 第 2 轮：技能牌教学
这一轮开始正式介绍技能牌。教学技能必须非常容易理解，效果应能够直接从画面中观察到。建议选择“给对方 Agent 添加干扰信息”或其他足够直观的效果，不要选择多层条件、延迟触发、长期状态、复杂数值修改或需要理解多个机制才能判断是否生效的技能。

### Step 15｜介绍技能牌
显示第 2 轮关键词后，高亮教学技能牌，提示：“除了派 Agent，你还可以使用技能干扰对手。”玩家点击技能牌查看效果。技能说明保持卡牌正常描述，不额外弹出长篇规则。随后提示：“这次使用这张技能。”

### Step 16｜打出技能牌
玩家使用指定技能牌，扣除对应 Token，并播放技能效果动画。例如技能飞向对方 Agent，对方 Agent 出现“干扰”状态标记。提示：“技能牌使用后立即生效。”技能牌进入弃牌状态。

### Step 17｜选择是否增加新 Agent
这一轮开始降低强制程度。根据关键词高亮两张可用 Agent，但不直接指定唯一答案。提示：“场上的 Agent 会继续作答。你也可以再派一个新的 Agent。”允许玩家再打一张 Agent，或者不打新的 Agent。教学脚本需要保证两种行为都不会使教程无法继续。

### Step 18｜结束出牌
玩家点击结束出牌，对手进行预设行动，随后揭晓第 2 道完整题目。

## 10. 第 2 轮：学习同结果时比较 Token
这一轮应故意安排双方最终都答对，从而自然引出 Token 决胜机制。

### Step 19｜双方都答对
双方 Agent 完成回答后，显示 `你：正确`、`对手：正确`，短暂停顿并提示：“双方都答对了。”随后高亮“本轮 Token 消耗”，例如显示 `你：2 Token`、`对手：4 Token`，提示：“结果相同时，本轮消耗 Token 更少的一方得分。”玩家获得 `+1`，积分从 `1 → 2`。

这里比较的只包括本轮新打出的卡牌 Token，以前已经在场上的 Agent 不重复计算 Token。

## 11. 第 3 轮：让玩家自己完成
第三轮是教程最重要的“放手”阶段，不要再一步一步告诉玩家具体应该打哪张牌。

### Step 20｜第三轮开始
自动执行 Token 恢复、Token 上限 +1、抽 2 张牌、展示题目关键词，不再弹出解释。短暂停顿后提示：“现在由你决定这一轮怎么出牌。”此时解除大部分教学锁定。

### Step 21｜允许玩家自主决策
玩家可以查看当前关键词、查看手牌、查看场上已有 Agent、使用技能牌、派出最多一张新的 Agent、保存 Token，或者直接结束出牌。不要提示“正确答案”。只保留非常弱的辅助：如果玩家长时间没有操作，可以轻微高亮手牌和结束出牌按钮，不要弹规则说明。

## 12. 第 3 轮结算与教程胜利
教学数据应提前设计，让玩家在正常操作情况下这一轮获得第 3 分。完成回答和判定后，积分例如从 `2 → 3`，显示 `3 : 1`，随后进入胜利动画。

## 13. 特殊情况：双方同时达到 3 分
如果教学脚本因为玩家选择产生 `3 : 3`，不要宣布平局。显示一句简短提示：“比分相同，继续加赛！”然后进入下一轮。后续继续按照正常规则执行 Token 上限 +1 并回满、抽 2 张牌、展示关键词、玩家自由出牌，直到某轮结束后一方积分领先。教学局数据设计应尽量避免这种情况，让绝大多数玩家在第 3 轮结束教程。

## 14. 教程结束
胜利动画结束后进入教程完成页。页面只需要突出“教学完成”和最终比分，不要再次把所有规则总结一遍。提供一个主要按钮：“开始真正的对战”。如果需要增加辅助入口，可以提供“重新进行教程”，但不要强制玩家再次阅读规则。

## 15. 教程中的操作限制
**第一轮：**严格限制，只能选择指定 Agent，不能使用技能牌，必须主动点击结束出牌。目的：保证玩家完成第一次完整循环。

**第二轮：**部分限制，必须至少使用一次指定技能牌，Agent 允许有限自由选择，可以决定是否增加新 Agent。目的：开始形成策略意识。

**第三轮：**基本解除限制，只保留正式游戏原本存在的规则限制。目的：验证玩家已经能够自己完成完整一轮。

## 16. 提示文本设计规则
所有教程提示尽量控制在一句。推荐使用：“根据关键词选择一个 Agent。”“打出 Agent 会消耗 Token。”“它答对了，会继续留在场上。”“这一轮，它不用再次消耗 Token。”“每轮开始都会获得更多 Token。”“试试用技能干扰对手。”“双方结果相同时，更省 Token 的一方得分。”“现在由你决定怎么出牌。”

避免使用大段定义，例如：“Agent 是一种代表真实 AI 模型的卡牌，它被部署到场上之后将在当前以及之后所有回合……”教程应该让玩家通过实际发生的事情理解规则，而不是通过阅读定义理解规则。

## 17. 实现要求
教程本质上是一套独立于 UI 坐标的状态机。建议状态结构：

`TUTORIAL_DECK_BUILD → TUTORIAL_HERO_SELECT → TUTORIAL_INITIAL_DRAW → TUTORIAL_R1_KEYWORD → TUTORIAL_R1_PLAY_AGENT → TUTORIAL_R1_END_PLAY → TUTORIAL_R1_REVEAL → TUTORIAL_R1_ANSWER → TUTORIAL_R1_SCORE → TUTORIAL_R2_REFRESH → TUTORIAL_R2_DRAW → TUTORIAL_R2_SKILL → TUTORIAL_R2_PLAY → TUTORIAL_R2_REVEAL → TUTORIAL_R2_SCORE → TUTORIAL_R3_FREE_PLAY → TUTORIAL_R3_REVEAL → TUTORIAL_R3_SCORE → TUTORIAL_COMPLETE`

每一个状态至少包含：`tutorialId`、`currentStep`、`highlightTargets`、`disabledActions`、`instructionText`、`requiredAction`、`completionCondition`、`nextStep`。

不要把教程逻辑写死在某个按钮坐标或某个页面 DOM 层级中。教程只依赖语义化游戏元素，例如：`deckCounter`、`heroCard`、`hand`、`agentCard`、`skillCard`、`tokenCounter`、`keywordPanel`、`battlefieldAgent`、`endTurnButton`、`answerResult`、`roundTokenCost`、`scoreBoard`。这样即使后续 UI 重新设计，也只需要重新绑定对应元素，不需要重写整套教程逻辑。

## 18. 最终体验标准
一个完全不了解游戏的玩家结束教程后，应该能够不看规则说明回答以下问题：

- 比赛前要做什么？——组 20 张牌并选择英雄。
- 题目什么时候能看到？——双方出完牌之后。
- Agent 打出去以后下一轮还在吗？——答对就继续留场。
- 下一轮还要为它付 Token 吗？——不用。
- 技能牌有什么用？——影响自己或对方的对局结果。
- 双方都答对怎么办？——比较这一轮谁花的 Token 少。
- 怎么赢？——先拿到 3 分；如果双方同时达到 3 分，则继续比赛，直到一方单独领先。

如果玩家能够自然理解这些内容，而不是背下来，教程即完成目标。
