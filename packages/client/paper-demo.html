一 · 米色纸纹理

① 纯底色 --paper
② + 大尺度斑驳
③ + 细颗粒
④ + 暗角（完整）

整页背景就是第四块的做法，两层噪声都烘焙成 data URI 背景图，用 multiply 压在底色上。
② 大尺度斑驳：低频柏林噪声 fractalNoise（baseFrequency 0.0059 ≈ 一团 170px、 numOctaves 2）当高度场，交给 feDiffuseLighting 打一束斜光 （surfaceScale 15、方位角 45°、仰角 56°）。光是照在噪声的起伏上，出来的是纸纤维的凹凸浮雕， 比把噪声直接当灰度铺上去「纸」得多。feComponentTransfer 把打光结果线性压到 0.89～1.0， 并且故意让上四分之一顶到 1.0 被截断：受光面就是底色本身，只有背光的纤维才真的压暗。 不截断的话整张纸会均匀发灰，看着像皮革；截断后平均只掉 2% 亮度，纸色不跑掉。 三个通道斜率不同（B 最陡）所以暗部偏暖，像旧纸的黄斑。 这一层整体只叠 70%（--mottle-alpha）：浮雕本身够重，全量压上去纸会显得「起皱」。
③ 细颗粒：高频噪声（baseFrequency 0.63 / numOctaves 3）压到 0.87～1.0， 截断点落在中位数上，颗粒只往下压不往上提，补 1～5px 的纸面粗糙度。 这个尺度上光影就是噪点本身，不需要再打光。它只是薄薄一层砂面，所以几乎全留（0.92）。
④ 暗角：一层超大范围的 radial-gradient（rgba 浓度 0.189），只是让四周比中间稍沉一点。
打光很贵，所以是整块 rect 连 filter 一起烘进 data URI（浏览器只在首次解码时算一次）， 而不是当成实时的 CSS filter。图块 900px 并开 stitchTiles，噪声在图块边界首尾相接， 平铺时看不出网格。纹理做成可复用的 .grain，两层分别铺在 ::before（压在内容下） 和 ::after（盖在文字上），各自有独立的 opacity； pointer-events: none 不影响点击、border-radius: inherit 自动贴合宿主圆角。 因为 ::before 被纹理占用了，卡牌 / 卡背 / 按钮的内框细线改成真实的 <i class="frame">。
纹理层是 position: absolute 铺满整篇文档，跟着内容一起滚；只有暗角还留在视口级别 （background-attachment: fixed）——暗角是打在纸上的灯光，钉住反而自然。
右上角的调参面板可以实时改这两层的参数：拖滑条会按当前值重新生成两个 data URI 写回 :root，全页（背景、卡面、按钮、卡背）一起变；不透明度和暗角浓度是独立 CSS 变量， 拖它们不重算噪声。选好之后按「复制当前参数」，得到一段可以直接粘进 :root 的完整 CSS。

二 · 结束回合按钮

← 常态（可 hover / 按下） · 禁用态

深墨蓝匾额：外层 1px 边框，.frame 做内缩 3px 的第二道细线。 表面纹理走 .grain.on-dark：跟纸面用的是同两张图，只是先 invert 再 screen——screen 只能提亮，纤维就从压暗的丝缕翻成微微发亮的丝缕， 深色底上不会出现一块块黑斑。 hover 时内线转赭红、文字转暖白并轻微提亮底色；active 下压 1px。 禁用态用灰底 + saturate(.25) 一次性去色。

五 · 卡背 / 空卡槽

← 实体卡背（墨蓝、纹样明显） · 空槽（同结构，虚线框 + 整体压淡）

卡背和空槽是同一套 DOM 结构，只靠一个 .is-slot 修饰类切换： 背景换成近乎透明的墨蓝、边框改虚线、罗盘不透明度从 0.62 降到 0.28。 罗盘纹样是内联 SVG 的同心圆 + 十字刻度 + 斜向短刻度 + 中央四角星， 全部 currentColor（米色），套 #rough-compass（scale 2.0，比图标小， 因为线更长、更细，位移放大后容易断）。
